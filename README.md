# CO-Cal

## 1. 웹 서비스 주제
사용자들이 함께 스터디 일정을 공유하고, 날짜별 학습 내용을 기록할 수 있는 웹 서비스

---

## 2. 주제 선정 배경 및 이유
* 스터디 모임에서 일정 조율과 학습 내용 공유의 번거로움을 해결합니다.
* 웹 상에서 모두가 같은 달력을 보고 일정과 공부 기록을 함께 관리할 수 있는 서비스를 기획했습니다.
* 공휴일을 자동으로 표시하여 스터디 일정을 쉽게 조정할 수 있도록 지원할 예정입니다.

---

## 3. 개발언어 및 사용도구/라이브러리
* **Frontend:** HTML, CSS, JavaScript
* **Backend:** PHP, Node.js
* **Database:** MySQL
* **API:** Calendarific API
* **협업 Tool:** GitHub

---

## 4. 팀 멤버 별 담당 업무

### 조수영: 백엔드 (데이터베이스 및 핵심 기능)
* 로그인, 회원가입 기능 개발 (PHP 또는 Node.js)
* 캘린더에 일정을 저장하고, 불러오고, 삭제하는 기능 (CRUD) 개발

### 서윤재: 백엔드 (API 연동 및 보조 기능)
* Calendarific API를 연동하여 캘린더에 공휴일 정보 표시하기
* 스터디 그룹을 만들고 초대하는 기능 개발

### 정지은: 프론트엔드 (화면 구현)
* HTML/CSS를 사용한 메인 페이지, 로그인/회원가입 페이지 디자인
* JavaScript를 이용한 메인 캘린더 화면 기능 구현
